# 机器学习学习笔记与代码实践

这是一个用于记录个人机器学习学习过程的仓库，内容主要整理自黑马程序员机器学习课程，包括课程资料、个人练习代码、学习笔记以及笔记中使用的图片。

本仓库以学习、复习和代码实践为目的，并非完整的生产级项目。

## 内容说明

- `data/`：黑马程序员机器学习课程的原始学习资料，包含各章节资料、案例代码、数据集和思维导图等。
- `program/`：个人学习过程中编写和调试的代码。这里的代码最初由我根据课程内容自行练习完成；由于最初没有添加完整注释，在确认代码能够正常运行后，又将课程资料中的参考代码和注释整理进来，方便后续对照、理解与复习。因此，该目录中的部分代码与课程示例代码相同或相近。
- `机器学习.md`：机器学习课程的个人学习笔记。
- `机器学习.assets/`：`机器学习.md` 引用的图片、公式截图和案例结果图，请与 Markdown 笔记放在相对位置下使用。
- `机器学习.pdf`：由学习笔记导出的 PDF 版本，便于直接阅读和分享。

## 学习内容

目前仓库覆盖的主要内容有：

- 机器学习基本概念、建模流程与特征工程
- KNN 分类与回归、数据归一化和标准化
- 交叉验证、网格搜索及手写数字识别
- 线性回归、梯度下降、L1/L2 正则化
- 逻辑回归及常用分类评估指标
- 决策树分类与回归
- 随机森林、AdaBoost、GBDT 和 XGBoost
- 朴素贝叶斯与中文文本情感分析
- K-Means 聚类及聚类效果评估
- 南方电网电力负荷预测综合案例

## 阅读建议

1. 先阅读 `机器学习.md` 或 `机器学习.pdf`，了解对应算法的概念和流程。
2. 进入 `program/` 中相应章节，结合代码逐步运行和调试。
3. 遇到不理解的实现时，可与 `data/黑马程序员_机器学习资料/` 中的原始课程资料进行对照。
4. 修改参数、数据划分比例或模型配置，观察结果变化并记录自己的理解。
